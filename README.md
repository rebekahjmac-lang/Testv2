# My First App

A tiny native Android sample app written in Java. It displays a welcome message and a button that counts taps.

## Build an APK using GitHub Actions
1. Create a GitHub repository and upload all files in this project.
2. Open the repository's **Actions** tab.
3. Select **Build Android APK**, then choose **Run workflow**.
4. When the run finishes, open it and download the `MyFirstApp-debug-apk` artifact.
5. Extract the ZIP file to get `app-debug.apk`.

The debug APK is for testing. Android may ask you to allow installation from the browser or file manager you use.
